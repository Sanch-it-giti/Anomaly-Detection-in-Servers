# M7A causal interval design — synthetic engineering only

7 November2026. Read the M7 readiness plan and original DAF-R research design, especially sections4.3,6 and the chronological protocol. The original explicitly requires **both90% and95% intervals**, complete-policy/horizon calibration, a discrete finite-sample rank, minimum100 and maximum288 prior scores. Therefore this milestone implements both levels, rather than silently replacing the approved design with90% alone. No original scientific document/configuration is modified. Reliability-based selection eligibility and ACI are future alternatives, not part of this milestone.

## Frozen construction

For n genuinely matured absolute errors of this same complete policy/version/horizon/current era, choose rank ceil((n+1)*p/100) for p90 or95 and take that exact smallest order statistic. Integer arithmetic `((n+1)*p+99)//100` avoids floating-rank interpolation/rounding. If n<100 or rank>n, issue null bounds with an explicit unavailable status, retaining the original center. No infinite width is replaced with zero. All supported intervals are symmetric center±q. Genuine zero residual/zero width are valid. Endpoints and centers are **not clipped** to[0,100]; widths/coverage use the raw bounds, so out-of-physical-range endpoints remain visible. This avoids hiding failures via clipping and does not change point predictions. Synthetic CPU observations themselves remain bounded; this is not evidence about real-series bounds.

Buffers hold at most288 genuine scores and expire targets before origin−287 grid ticks. Each support receipt carries count, earliest/latest targets and a deterministic SHA-256 of ordered forecast/outcome IDs, target timestamps and residuals. Expiration is by elapsed grid time, never compressed genuine-sample positions. Separate90/95 intervals share the same policy/horizon score set but distinct ranks/outcomes. The first100 scores may include forecasts whose intervals were unavailable; interval availability must not prevent causal cold-start calibration.

Keys are complete-policy ID, policy version, horizon and current era. Fixed shadow experts calibrate only their own actually issued expert forecasts. Persistence calibrates its own baseline. Adaptive calibrates its actual issued selected/fallback centers, as mandated by the original design and frozen V2 support convention. Its own fallback errors explicitly stay attributed to adaptive, never borrowed from persistence or a chosen expert. Thus a fallback can receive only its complete policy's supported interval under this declared mixed-source policy rule, not an expert's interval masquerading as fallback calibration. Support is **not a source-conditional guarantee**. Actual requested expert/version/source remain in each immutable forecast/score. Selector switches retain complete-policy support; model metadata/version changes are rejected by this milestone rather than silently reusing old errors under a new model.

## Causality, event order and isolation

The unchanged M5A deterministic mock selector and unchanged M6A persistence drift source receive the same generated tick. External interval processing then clocks the current grid/era, resolves previously issued interval outcomes, inserts eligible genuinely matured policy errors, and issues intervals around current immutable point forecasts. Current-target errors become available through that origin and may calibrate its future-target interval. No pending residual, future availability, fitted residual or hidden real calibration block enters. Source point issuance preceding the external interval attachment is safe because no interval feedback enters selection/forecasting/drift. Enabled/disabled runs must produce identical point forecast/selection/drift records.

The engine enforces maturity-before-interval-issuance within each tick, exact timestamps and horizon links, one stream identity, duplicate rejection, forecast immutability and a fourth-missing reset exactly once per long gap. Missing targets create unavailable outcomes, never error/coverage samples. Genuine old-era targets can score their original issued intervals, but their errors do not seed new-era calibration. All-missing/no-history/stale cases abstain; unavailable expert attempts have null interval bounds and cannot contribute residuals. Beyond-stream forecasts/intervals remain pending with no coverage outcomes.

Coverage uses inclusive lower≤genuine target≤upper on **available intervals only**, with available-scored denominator reported explicitly. Interval availability among issued centers and conditional availability among genuine matured centers are reported separately from forecast availability, missing targets, pending and unissued attempts. Proper interval score is width+(2/alpha)*max(lower−y,0,y−upper). Width is reported both at issuance and genuine scoring; unavailable widths are null, not zero. Per policy/horizon/nominal results remain separate; no pooled headline accuracy/coverage claim is made.

## Prespecified verification and limits

Ten fixtures are fixed before saved execution: stable sinusoidal errors, growing/shrinking amplitude, abrupt amplitude step, isolated extreme, short gaps, leading/long/trailing gap recovery, insufficient support, declared numerical forecast failures, and prolonged expert failures for genuine time-based calibration expiry without a telemetry gap. The latter spans490 ticks with mock failures at state steps150–449; others360, except insufficient support60. All generated values/labels are unavailable to previous forecasts. Correlated/overlapping h12 errors remain dependent. Faults use registered deterministic mock implementations, not real fitted ARIMA/XGBoost models or training.

Unit tests and a separately coded saved-ledger auditor check exact ranks, source/era support, expiry, delayed feedback, missing/pending targets, coverage/width/score arithmetic, future suffix invariance, centers/selection/drift parity, faults, resets, immutable records, no-overwrite and protected historical hashes/checkpoints. Saved runs require a frozen source/provenance gate after all341 existing plus new tests pass. No detector/selector changes or response callbacks are authorized. Versioned output namespaces are exclusive. Standard-library buffer logic,2304-tick cap and4GiB RSS guard keep the pilot small; audit ledgers remain bounded by the run cap rather than production-scale storage.

Rolling residual intervals under serial dependence, drift, changing policy mixtures and selected calibration support **do not automatically have exchangeability-based finite-sample, conditional or local coverage guarantees**. Synthetic empirical coverage and width are engineering diagnostics only. Unfavorable undercoverage/overwide intervals will be retained; settings will not be retuned. M5B-2's lack of adaptive improvement and M6A detector misses/repeated alarms remain unchanged. Real calibration/final/confirmation observations stay restricted. M7B real-backend integration or data evaluation needs separate scope and authorization.
